CA117 Data Structure

Learn Arrays, Stack, Queue, Linked List with funny examples and diagrams.

Array

Array ek data structure hai jisme same type ke elements ek line me store hote hain. 

Index: 0  1  2  3  4
Array |10|20|30|40|50|

Example Code

int arr[5] = {10,20,30,40,50};

Stack

Stack ek data structure hai jo LIFO (Last In First Out) rule follow karta hai. Jo element last me aata hai wahi sabse pehle nikalta hai. 

      -----
Top ->| 30 |
      -----
      | 20 |
      -----
      | 10 |
      -----

Example: Plates ka stack. Jo plate sabse upar rakhi hoti hai wahi pehle uthai jaati hai.

Queue

Queue ek data structure hai jo FIFO (First In First Out) rule follow karta hai. Jo element sabse pehle aata hai wahi sabse pehle nikalta hai. 

Front -> |10| |20| |30| |40| <- Rear

Example: Bus line. Jo aadmi line me sabse pehle khada hota hai wahi pehle bus me chadta hai.
