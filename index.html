CA117 Data Structure with C

Data Structure ka matlab hai data ko organize karne ka tarika taaki usko efficiently use kiya ja sake.

1️⃣ Array

Array ek collection hota hai same type ke elements ka jo memory me contiguous location par store hote hain. 

Index: 0  1  2  3  4
Array |10|20|30|40|50|

Example Code

int arr[5] = {10,20,30,40,50};

2️⃣ Linked List

Linked List ek linear data structure hai jisme elements nodes ke form me store hote hain. Har node me data aur next node ka address hota hai. 

[10 | next] → [20 | next] → [30 | next] → NULL

Real life example: Train ke coaches.

3️⃣ Stack

Stack ek data structure hai jo LIFO (Last In First Out) principle par kaam karta hai. Jo element last me aata hai wahi sabse pehle nikalta hai. 

      -----
Top ->| 30 |
      -----
      | 20 |
      -----
      | 10 |
      -----

Example: Plates ka stack.

4️⃣ Queue

Queue ek data structure hai jo FIFO (First In First Out) rule follow karta hai. Jo element sabse pehle aata hai wahi sabse pehle nikalta hai. 

Front -> |10| |20| |30| |40| <- Rear

Example: Bus line.

5️⃣ Tree

Tree ek hierarchical data structure hai jisme nodes parent-child relation me arranged hote hain. 

       A
      / \
     B   C
    / \   \
   D   E   F

Example: Family tree.

6️⃣ Graph

Graph ek data structure hai jisme nodes aur edges hote hain jo relationship show karte hain. 

A ---- B
|      |
|      |
C ---- D

Example: Google Maps navigation.
